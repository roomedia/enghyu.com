Underdog, 음성 모델 'Bark 3.0' 출시 — 163MB로 Whisper large-v3보다 낮은 오류율 주장 (10/21, Underdog 공식)

2026-10-21 Underdog 공식 발표 · ax-trend 이슈 #3383 · 온디바이스, 음성 에이전트

핵심 — 163MB 모델이 Whisper large-v3보다 낮은 오류율을 주장한다

  • Underdog AI가 공식 X 계정(@UnderdogAI)으로 음성 인식 모델 Bark 3.0 출시를 발표했다 (2026-10-21 게시, Underdog 공식).
  • "the #1 frontier speech model"이라고 소개했다 (Underdog 공식 X).
  • 모델 크기는 163MB 다운로드. NVIDIA Parakeet보다 15배, OpenAI Whisper large-v3보다 57배 작다고 밝혔다 (Underdog 공식).
  • 영어 전용, 라이선스는 CC-BY 4.0 오픈소스다. Hugging Face에서 받을 수 있다 (Underdog 공식).
  • 패밀리 구성: Clean 180MB, 3.0 163MB, 3.0 Plus 180MB, 3.0 Pro 1.25GB (제품 페이지 underdog.ai/bark, 2026-10-15 게시).

크기 — 57배 작다는 주장의 실무 의미

  • Whisper large-v3(약 1.5GB급)이 GPU 메모리를 요구하는 것과 달리, 163MB는 CPU·노트북·휴대폰에 올릴 수 있는 범위다 (이슈 배경).
  • 녹음이 기기를 떠나지 않는다. 회의 전사처럼 민감한 오디오를 클라우드 API에 보내지 않아도 되는 구조다 (이슈 배경).
  • 단, 크기 수치 자체도 Underdog의 주장이다. 다운로드 후 실제 바이트로 확인할 수 있는 부분이다.

오류율 — 자사 측정이라 그대로 믿을 순 없다

  • 회의 녹음(AMI) 단어 오류율 자사 측정: Bark 3.0 7.82%, Parakeet 9.42%, Whisper large-v3 13.63% (Underdog 공식).
  • 전부 자사 측정이다. 독립 벤치마크가 아직 없다 (이슈 배경).
  • 숫자가 사실이라면 회의 전사·받아쓰기의 기본값이 클라우드 API에서 로컬 모델로 옮겨갈 수 있다 (이슈 배경).
  • 발표 게시물 반응: 조회 10.6만, 좋아요 2.6천, 북마크 2.8천 (게시 당일 확인).

속도·라이선스 — 로컬에서 돌릴 조건은 갖췄다

  • 속도: MacBook에서 1분 오디오 전사에 0.25초 미만 (Underdog 공식).
  • 제품 페이지는 M5 Max MacBook Pro에서 5분 오디오를 0.5초에 전사했다고 적었다. 실시간 대비 최대 595배 (제품 페이지, 2026-10-15 게시).
  • CC-BY 4.0이라 상업 이용이 가능하다. 출처 표기만 지키면 된다.
  • 영어 전용이라 한국어 회의록에는 지금은 못 쓴다. 영문 회의·팟캐스트 자막 용도로만 성립한다 (이슈 배경).

AX TF 관점. 영어 회의 녹음이 있다면 163MB 다운로드 → 사내 벤치로 Whisper large-v3와 직접 비교가 한 시간짜리 실험이다 (이슈 배경). 자사 측정 7.82%가 재현되는지만 확인하면, 회의 전사 파이프라인의 클라우드 API 비용·프라이버시 리스크를 숫자로 다시 계산할 수 있다. 영어 전용이라 범위는 영문 자료로 한정된다.

아직 안 밝혀진 것 — 자사 측정·영어 전용·초기 스타트업

⚠️ 미확인: AMI 오류율 비교는 Underdog 자체 수치로, 독립 벤치마크가 아직 없다 (이슈 배경). 다국어 성능은 공개되지 않았다 (영어 전용). 회사 규모: 계정은 2026년 9월 개설, 팔로워 8.2천의 초기 스타트업이라 지속 공급 여부는 미확인 (이슈 배경). 제품 페이지 날짜는 10월 15일로, 실제 공개와 발표 게시물 사이에 일주일 간격이 있다 (이슈 배경). Underdog는 "100% 온디바이스"를 내건 개인 AI 앱으로, ax-trend 이슈 #3063에서 초대 베타를 다뤘다.
