ElevenLabs 'Eleven Realtime' — 말로 듣고 추론하고 바로 답하는 speech-to-speech 음성 에이전트 모델

2026-10-23 · AX 트렌드 · 원문 이슈 #3379

2026년 10월 20일, ElevenLabs가 실시간 음성 에이전트용 speech-to-speech(말→말) 모델 패밀리 Eleven Realtime을 공개했다. v1 Mini와 v1 Max 2종으로 출시됐다 (the-decoder, 2026-10-20).

음성 인식·턴테이킹·음성 활동 감지·음성 생성을 하나의 시스템으로 통합한 구조다. ElevenLabs는 "설정 전문가가 되지 않아도 자연스러운 음성 에이전트를 만들 수 있다"는 점을 내세운다.

핵심 수치. v1 Max — Big Bench Audio 98.8%, 평균 첫 오디오 응답 0.57초. v1 Mini — 75.9%, 0.62초. 90개 이상 언어, 17,000개 이상 음성 사용 가능.

모델 두 종: Mini는 대화용, Max는 추론용

  • v1 Mini — AI 어시스턴트·교사·인터랙티브 캐릭터 같은 자연스러운 대화용
  • v1 Max — 고객 지원·리드 검증·다단계 툴 사용 워크플로 같은 추론이 필요한 작업용

둘 다 90개 이상 언어를 지원하고, ElevenLabs 라이브러리의 17,000개 이상 음성을 쓸 수 있다 (analyticsindiamag).

ElevenLabs는 "Artificial Analysis 리더보드에서 Max보다 빠르고 정확한 모델은 현재 없다"고 주장했다. 단, 43개 평가 모델 중 Max는 3위다. StepAudio 3 Realtime(99.7%)과 Qwen Audio 3.0 Realtime Plus(99.2%)가 앞섰다 (the-decoder; iaenunminuto).

OpenAI 호환: 코드 2줄로 갈아타기

ElevenAgents 플랫폼과 OpenAI 호환 Realtime API(WebSocket, WebRTC는 출시 시점 미지원)로 제공된다. OpenAI Realtime API를 쓰던 팀은 엔드포인트와 모델명 2가지만 바꾸면 마이그레이션할 수 있다. OpenAI SDK도 그대로 쓴다 (journaldunet).

// 개념 코드: OpenAI Realtime API → Eleven Realtime 마이그레이션
val client = RealtimeClient(
    endpoint = "https://api.elevenlabs.io/v1/realtime",  // ① 엔드포인트만 변경
    model    = "eleven-realtime-v1",                      // ② 모델명만 변경
)
// OpenAI SDK 호출부는 그대로

요금: 분당 과금 + 토큰 과금 — 단가는 미공개

요금은 분당 오디오 연결 시간 + 토큰 사용량 기준이다. v1 Max가 v1 Mini보다 비싸다. 구체적인 토큰 단가는 아직 공개되지 않았다 (the-decoder; journaldunet). 이중 과금 구조에서 에이전트 워크로드의 총비용 산정은 검증이 필요하다.

배경: 10월 셋째 주, 음성 AI 릴리스가 몰렸다

음성 에이전트는 그동안 STT→LLM→TTS를 따로 붙이는 조립식 구조가 표준이었다. ElevenLabs는 하나로 튜닝한 단일 시스템으로 맞섰다. 같은 날 Mistral이 Voxtral 3(음성 에이전트 스택)을 내놓았다. 10월 셋째 주는 음성 AI 릴리스가 몰린 주간이 됐다 (관련 글: Mistral 'Voxtral 3').

⚠️ 미확인: 98.8%·0.57초는 ElevenLabs가 제공한 조건에서의 Artificial Analysis 독립 측정이다. 실제 프로덕션(네트워크 지연·프롬프트 처리·툴 호출 포함)에서의 체감 지연은 미확인이다. 토큰 단가가 미공개라 실제 운영 비용 산정이 불가능하다. Mini가 Full-Duplex-Bench(일시정지·중단·턴테이킹·백채널 평가)에서 95.8%로 Max(94.1%)를 앞섰다. 추론이 강한 Max가 대화 역학에서는 오히려 뒤처지는 이유에 대한 설명은 없다 (analyticsindiamag). 전사(transcript)를 제공하지 않는 구조라 기존 기업의 안전·컴플라이언스 툴링과 충돌할 수 있다는 지적도 있다 (techtimes).
AX TF 관점. Android 앱에 음성 에이전트(고객 상담·튜터·음성 비서)를 붙이는 팀에게 즉시 써먹을 수 있는 선택지다. OpenAI Realtime API 호환이라 기존 OpenAI 기반 음성 워크플로가 있다면 코드 2줄 변경으로 갈아탈 수 있어 도입 장벽이 낮다. 다만 전사 미제공·토큰 단가 미공개는 엔터프라이즈 도입 전 확인이 필요한 리스크다.
