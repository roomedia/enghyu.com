NVIDIA, 오픈모델 포트폴리오 대확장 — Nemotron Retriever·Kumo·Cosmos 3.5·Alpamayo 2 Edge·BioNeMo RFD4-Proteina·Ising, GTC Berlin (10/21, NVIDIA 공식)

2026-10-21 NVIDIA 공식 블로그 · ax-trend 이슈 #3386 · GTC Berlin

핵심 — 한 번의 발표에 6개 분야의 오픈 모델이 나왔다

  • NVIDIA는 GTC Berlin 시점에 공식 블로그에서 언어·로보틱스·바이오·양자 컴퓨팅을 가로지르는 오픈 모델 포트폴리오 확장을 발표했다. 블로그 게시일은 2026-10-21이다.
  • 이번 묶음은 Nemotron Retriever·Kumo·Cosmos 3.5·Alpamayo 2 Edge·BioNeMo RFD4-Proteina·Ising 6종이다. 10/15 Nemotron 3.5 발표에 이은 두 번째 물결이다.
  • 이번 발표의 프레임은 유럽의 소버린 인텔리전스다. 각국 기업·연구소가 자체 데이터로 커스터마이즈하고 자체 인프라에 배포할 수 있는 오픈 모델 묶음을 전면에 내세운 점이 10/15 발표와 다르다.

검색과 구조화 데이터 — Nemotron Retriever·Kumo

  • Nemotron Retriever는 임베딩·리랭킹·문서 파싱용 신규 모델군이다. Hugging Face·파트너 플랫폼·build.nvidia.com의 NIM 마이크로서비스로 제공된다. RAG 파이프라인의 검색 계층을 통째로 교체할 수 있는 위치다.
  • Kumo는 구조화된 비즈니스 데이터를 위한 오픈 웨이트 파운데이션 모델·라이브러리·도구다. 예측·포캐스팅·이상 탐지 모델을 제공하고, 조직이 자체 데이터로 파인튜닝할 수 있다.
  • Kumo Structured는 Hugging Face에, Kumo Engine(오픈 라이브러리 스택)은 GitHub에 공개됐다. Cognite·Coinbase·Databricks·DoorDash·Revolut·Tubi가 Kumo를 쓰고 있고, Snowflake 고객사들도 광고·에너지·금융·리테일 AI 개발에 Kumo를 사용 중이다.
에이전트가 기업 테이블 데이터를 다뤄야 하는 AX 업무라면, Kumo는 LLM 프롬프트로 테이블을 찔러보는 방식이 아니라 전용 파운데이션 모델로 예측·탐지를 붙이는 선택지를 준다.

로보틱스·자율주행 — Cosmos 3.5·Alpamayo 2 Edge

  • Cosmos 3.5는 로보틱스·자율주행·비전 에이전트용 월드 모델이다. 새로 도입된 Cosmos Data Factory(블루프린트+코어 에이전트 스킬)가 주행 시나리오·제품 결함·이미지 증강·이벤트 생성 데이터의 큐레이션·라벨링·생성·평가를 지원한다.
  • Porsche(Voxel51과)·ANYbotics(Encord와)·Zalando·CEVA Logistics(Sereact와)·Siemens가 Data Factory를 사용 중이다. Cosmos는 Hugging Face·GitHub·일부 추론 파트너에서 오픈 제공된다.
  • Alpamayo 2 Edge는 차량 내 실시간 장면 이해·모션 플래닝을 위한 소형 리즈닝 모델이다. Cosmos 3 Edge의 Nemotron 기반 파운데이션을 쓰고 NVIDIA DRIVE AGX Thor에 최적화됐다. 이달 중 GitHub·Hugging Face 다운로드 예정이다.

바이오·양자 — BioNeMo RFD4-Proteina·Ising

  • BioNeMo RFD4-Proteina는 NVIDIA와 워싱턴대 단백질디자인연구소(Baker Lab)의 오픈 단백질 디자인 모델이다. 단백질 서열과 3D 구조를 생성하며, 10개 이상 단백질 디자인 태스크에서 최고 성능을 내고, 200개 아미노산 단백질 벤치마크에서 RFdiffusion3 대비 약 13배 빠르게 설계를 생성한다고 주장한다. build.nvidia.com·NIM·GitHub·Hugging Face에서 제공된다.
  • Ising은 양자 슈퍼컴퓨터 개발을 위한 오픈 모델 패밀리다. 실시간 하드웨어 캘리브레이션부터 오류 정정까지 다룬다. IQM Quantum Computers가 양자 프로세서 캘리브레이션에 사용 중이고, SEEQC는 NVQLink+Ising 조합을, AWS는 AWS Parallel Computing Service에 Ising을 통합한다.
  • 그 밖에 Nemotron 3.5 Bolt E4B 4GB는 10/23 금요일 출시 예정이다. Nemotron은 Black Forest Labs·H-Company·Mistral이 참여한 Nemotron Coalition의 데이터·연구를 기반으로 한다.

배경 — 10/15 발표의 두 번째 물결, 프레임은 소버린 AI

지난주 10/15에 발표된 Nemotron 3.5 Super VL 120B·Bolt 74B-A9B(관련 이슈 #3278)에 이은 두 번째 물결이다. 10/15 발표가 대형 언어 모델 자체였다면, 이번 발표는 검색·구조화 데이터·로보틱스·바이오·양자까지 영역을 넓힌 포트폴리오 확장이다. 공통 분모는 오픈 웨이트와 자체 배포 가능성이다. 온디바이스·온프레미스 배포를 노리는 팀에게는 이번 묶음이 실질적인 메뉴가 된다.

왜 중요한지 — AX 실무에 바로 꽂히는 세 가지

RAG용 리트리버(Nemotron Retriever), 구조화 데이터 예측(Kumo), 로보틱스 시뮬레이션(Cosmos 3.5+Data Factory)이 모두 오픈 웨이트로 바로 내려받아 쓸 수 있다. 특히 Kumo는 에이전트가 기업 테이블 데이터를 다루는 AX 업무에, Cosmos Data Factory는 로보틱스 데이터 파이프라인에 직접 연결되는 실무형 자산이다.

아직 안 밝혀진 것 / 쟁점

  • 각 모델별 라이선스 조건 미공개: 오픈 웨이트 표현이나 세부 이용 조건은 블로그에 없다.
  • “10개 이상 태스크 최고 성능” 주장의 태스크 목록·평가 방법 미공개.
  • Cosmos 3.5가 Cosmos 3 대비 구체적으로 바뀐 점 미공개.
