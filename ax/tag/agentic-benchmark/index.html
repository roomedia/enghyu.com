10개의 글

#3471 Zhan-Yu Wu 등 'UserSWE' — 동적 사용자 시뮬레이션으로 멀티턴 코딩 에이전트 평가 (10/21, arXiv) 코딩 에이전트 평가를 싱글턴 이슈 리포트에서 실제 버그 수정 대화로. 동적 사용자 시뮬레이션과 매 턴 실행 기반 판정으로 11개 에이전트를 평가한 UserSWE.
#3449 Yanze Zhang 등 'MicroPerf-Bench' — 마이크로서비스 성능 최적화로 코딩 에이전트 실력 재기 (10/21, arXiv) MicroPerf-Bench는 마이크로서비스 시스템의 종단간 성능 최적화로 코딩 에이전트를 재는 벤치마크다. 1,755회 실행에서 최고 구성도 주입된 성능 저하의 42.0%만 회복했다.
#3447 Shota Fujikawa 등 'Agent Behavior Maps' — 에이전트를 실행 없이 행동 궤적으로 위치시키는 지도 (10/21, arXiv) Agent Behavior Maps는 LLM-하네스 조합을 공유 참조 궤적 위의 중심화된 행동 로그 가능도로 표현한다. 대상 에이전트의 새 환경 롤아웃이 필요 없다. 100개 LLM·4개 환경에서 ALFWorld 기반 좌표가 성능 예측을 지원하고 행동 유사도를 식별했다.
#3445 Chenxi Huang 등 'SysRB' — 코딩 에이전트는 시스템 크래시 원인을 아직 못 읽는다 (10/21, arXiv) 소스 트리 쌍 개입 실험 SysRB에서 최고 코딩 에이전트도 실제 크래시 중 over a quarter를 놓쳤다. 단일 커밋 차이의 트리 쌍 934개로 의심 코드 발견과 진짜 실행 추론을 분리해 재는 벤치마크.
#3444 Yunfeng Zhu 등 'Self-Report Leakage' — 에이전트 자기보고가 완성 판정을 오염시킨다 (10/21, arXiv) GUI 에이전트의 자기보고를 감사 판정에서 제외하면 dangerous-misreport 재현율이 Qwen3.5-35B-A3B에서 43.4pp 상승한다. report-trace 감사와 aware/blind 통제 개입으로 누수를 실측한 연구.
#3440 Yifan Sun 등 'Your Benchmark' — 벤치마크는 난이도 위의 경험적 측도라는 진단 (10/21, arXiv) 25개 벤치마크를 7개 도메인에서 난이도 축 위에 올려 진단한 연구. 실패 모드 두 가지(measure mismatch·coverage gaps)와 난이도 표적 재작성 알고리즘 BenchFill을 내놨다.
