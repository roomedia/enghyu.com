Elorian 'Glimpse' — 이미지를 보고 추론하는 비주얼 리즈닝 모델, GPT-6 Astra 대비 94% 저렴

2026-10-16 · 원문 이슈 #3326

미국 Palo Alto의 AI 스타트업 Elorian이 10월 16일(금) 첫 모델 Glimpse를 리서치 프리뷰로 공개했다 (TechCrunch 단독 보도). 핵심 메커니즘은 "visual scratch space" — 추론 중간에 원본 이미지로 되돌아가 특정 영역을 크롭하거나 비디오 프레임을 추출하고, 코드를 실행해 측정·비교한다.

CEO는 전 Google DeepMind 연구원 Andrew Dai. 그가 들려준 출발점이 재밌다: 보드게임 사진을 찍어 프론티어 모델에게 "누가 이기고 있냐"고 물었더니 답을 못 했다. 보드게임마다 고유한 visual language·iconography·symbol이 있는데 모델이 이를 직관적으로 이해하지 못했다는 것. "인간은 텍스트 없는 이케아 조립 설명서를 보고도 조립하는데, 왜 AI는 못하느냐"가 그의 문제 제기다.

개발자 관점 한 줄 요약: 멀티모달 에이전트의 이미지·비디오 처리 비용을 낮추는 "작지만 시각 추론에 강한" 옵션 하나가 생겼다. 앱 내 카메라·스크린샷 분석(UI 자동화, 문서·차트 해석) 워크로드에 직접 써먹을 수 있는 후보라는 점에서 주목할 만하다.

기존 멀티모달 vs Glimpse: 추론 루프가 다르다

기존 멀티모달 모델은 이미지를 한 번 보고 토큰으로 변환한 뒤부터는 텍스트로만 추론한다. 첫 인코딩에서 놓친 디테일은 이후 영원히 사라진다. Glimpse는 추론 과정에서 원본 이미지로 다시 돌아간다:

  • 크롭·줌 — 의심 영역을 확대해 재검사
  • 비디오 프레임 추출 — 쇼트폼 영상에서 필요한 프레임만 떼어내기
  • 코드 실행 — 크롭한 영역에 대해 측정·비교 연산 수행

아이디어 자체가 완전히 새로운 건 아니다. OpenAI는 2025년 o-시리즈에 추론 중 크롭·줌을 넣었고, CharTool 연구(2026년 8월 업데이트)는 이미지 크롭과 코드 기반 계산을 결합했다. Elorian의 차별점은 "그 메커니즘 하나에 맞춰 모델 전체를 설계하고 저렴하게 만들었다"는 주장이다. 소규모 팀이 수백 대의 GPU로 학습시켰고, 비교 대상 프론티어 시스템보다 "substantially smaller"하다고 한다.

가격: GPT-6 Astra 대비 94% 저렴

모델입력 / 1M tokens출력 / 1M tokens
Glimpse$0.60$3.00
GPT-6 Astra$10.00$50.00
Claude Opus 5.5$4.00$20.00
GPT-6.1 Sol$2.00$10.00

Elorian이 제시한 포지셔닝은 "Sonnet·Sol 같은 mid-level 모델보다 저렴하고, Haiku·Luna 같은 lightweight 모델보다 비싸다". 에이전트 비용 관점에서 이게 의미하는 바를 간단히 계산해보자. 회사 제시 단일 예시(LIBERO 태스크 로봇 플래닝)는 에피소드당 Glimpse $0.035 vs Astra $0.249였다.

# 이미지·비디오 처리 10,000회 에이전트 잡의 추론 비용 비교
INPUT_PER_CALL  = 8_000   # 이미지 토큰 (고해상도 스크린샷 기준)
OUTPUT_PER_CALL = 1_000   # 텍스트 출력 토큰
CALLS = 10_000

def cost(input_per_m, output_per_m):
    return CALLS * (INPUT_PER_CALL * input_per_m + OUTPUT_PER_CALL * output_per_m) / 1e6

print(f"Glimpse:   ${cost(0.60, 3.00):,.0f}")   # $78
print(f"Astra:     ${cost(10.00, 50.00):,.0f}")  # $1,300
print(f"Opus 5.5:  ${cost(4.00, 20.00):,.0f}")   # $520
# Glimpse ≈ 6% of Astra, 15% of Opus 5.5

실무 포인트: 시각 추론 품질이 "충분히" 좋다면, 월 100만 건 단위의 UI 자동화·스크린샷 회귀 검사 같은 워크로드에서 토큰 비용이 1/16로 떨어진다. 벤치마크 검증이 관건이다.

평가 결과: Astra를 넘은 두 영역

회사 자체 평가에 따르면 Glimpse는 두 태스크에서 GPT-6 Astra를 능가했고, 나머지 비주얼 리즈닝 태스크에서는 "competitive"한 결과를 보였다.

아직 미확인: 벤치마크는 전적으로 Elorian 자체 발표다. runtimewire는 "wins are narrow, company-reported results"이며 자사 표에서 GPT-6 Astra에 명확히 진 항목도 있다고 지적했다. 독립 검증 없이는 회사 주장으로 취급할 것. 또한 챗 인터페이스 접근성에 보도가 엇갈린다 — TechCrunch는 waitlist-only라고 전했으나 Elorian 자체 포스트는 "API와 chat UI를 통해 오늘 이용 가능"이라고 썼다. 실제 가용성은 미확인이다.

돈의 움직임: $55M 시드, $300M 밸류에이션

제품 출시 전 $55M 시드 라운드를 $300M 밸류에이션에 유치했다. Striker Venture Partners·Menlo Ventures·Altimeter Capital이 공동 리드했고, Nvidia와 Google 최고과학자 Jeff Dean이 참여했다. 회사는 6개월 전 스텔스에서 나왔다.

초기 타깃은 비디오 데이터를 대량 보유한 기업: 로봇 회사, 과학 연구소, 미디어·크리에이티브 회사. 장기 목표는 장면을 모델링해 액션을 선택하고 로봇을 직접 제어하는 방향이며, 내년 목표는 "the world's best visual reasoning model"이다.

왜 주목할 만한가: 비주얼 scratch space 방식이 프론티어 대비 1/5 스케일에서 통한다는 주장은 검증해볼 가치가 있다. 사실이라면 "작고 특화된 모델이 프론티어를 특정 태스크에서 이긴다"는 패턴이 시각 추론으로 확장되는 것이고, 이는 온디바이스·로컬 에이전트 스택(예: RTX Spark 노트북)의 기본 비주얼 모델 후보를 바꾼다. 다만 모든 수치는 회사 주장 — 우리 워크로드는 직접 측정해서 판단할 것.
