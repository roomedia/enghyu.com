Exa, AI 에이전트용 검색 API 'Exa 3.0' 출시 — 역대 최대 검색 품질 개선·신규 저가 티어 'Exa Lite' $4/1,000요청

2026-10-22 · AX 트렌드 · 원문 이슈 #3349

2026년 10월 19일, Exa가 AI 에이전트용 검색 API의 새 버전 Exa 3.0을 출시했다. 회사의 표현 그대로 "the largest improvement to search quality we've ever released"다. 올해 들어 Dynamic Highlights 리서치 프리뷰(8월), Agent Ultra(9월)에 이은 세 번째 대형 업데이트다.

핵심 수치 네 가지. 첫째, 자체 테스트 전 벤치마크 1위 주장: BrowseComp 91.8%, DSQA 88.2%, WebCode 75.5%. 둘째, 신규 저가 티어 Exa Lite — 1,000요청당 $4 (Exa Auto는 $7). 셋째, Dynamic Highlights 정식 제공(GA): 전체 페이지 텍스트 대비 95% 적은 토큰으로 답 품질 개선. 넷째, 인덱스 확장: 전자상거래 리스팅 12.7억 건, 로컬 비즈니스 2.11억+ 건 추가.

중요한 단서 하나. 공식 블로그는 "we tested"라고 썼다. 회사가 직접 돌린 테스트 결과라는 뜻이고, 독립 검증은 아직 없다. 1위 주장도 이 맥락에서 읽어야 한다.

가격 — Exa Lite 신규 티어

새 저가 검색 타입 Exa Lite가 핵심이다. 1,000요청당 $4다. 기존 Exa Auto는 $7/1,000요청이다. 가격 차이는 컴퓨트에서 나온다. Lite는 Auto와 같은 인덱스를 사용한다. Auto는 검색 스택 전반 — candidate generation·highlights·ranking — 에 더 많은 컴퓨트를 쓴다.

개발자 입장에서 읽는 법은 이렇다. 인덱스 커버리지는 같고, 랭킹 정교함에서 컴퓨트를 절약하는 티어다. 대량 그라운딩이 필요한 워크플로우는 Lite로 먼저 돌리고, 품질이 아쉬운 케이스만 Auto로 올리는 계층 전략이 바로 떠오른다.

Dynamic Highlights GA

Dynamic Highlights가 정식 제공(GA) 단계로 넘어왔다. 8월 리서치 프리뷰의 후속이다. 핵심 변화는 토큰 배분 방식이다. 각 페이지에서 따로 하이라이트를 뽑던 방식에서, 전체 결과 셋에 걸쳐 토큰을 배분하는 모델로 바꿨다. 결과: 전체 페이지 텍스트 대비 95% 적은 토큰으로 답 품질이 개선된다고 주장한다.

에이전트 비용 구조에서 컨텍스트 토큰은 가장 큰 항목이다. 그라운딩 단계에서 95% 토큰 절감이 실제로 재현된다면, 에이전트 서비스의 운영비는 눈에 띄게 줄어든다. 다만 이 수치도 회사 자체 측정치다. 실제 에이전트 궤적에서의 지연·비용 절감폭은 실측이 필요하다.

인덱스 확장

임베딩 모델을 역대 최대 컴퓨트·데이터로 재학습했고, 인덱스에 수십억 문서를 추가했다. 전자상거래 리스팅 12.7억 건(가격·재고 포함), 로컬 비즈니스 2.11억+ 건(영업시간·평점 포함)이다. 실시간 데이터도 들어갔다. 뉴스·스포츠·날씨·시장 데이터, 항공편·로컬 이벤트·대중교통·팟캐스트다.

개선된 highlights와 확장 인덱스는 추가 요금 없이 제공된다. API로 즉시 사용 가능하다. 제품 책임자 Shyam Kumar와 R&D 책임자 Liam Hinzman이 10월 21일 수요일 오후 1시(PT)에 라이브 Q&A를 진행할 예정이다.

⚠️ 미확인: 벤치마크 1위 주장은 "we tested" — 회사 직접 테스트 결과로 독립 검증이 아직 없다. "95% 적은 토큰"·"역대 최대 개선"도 회사 자체 측정치다. 실제 에이전트 궤적에서의 지연·비용 절감폭은 실측 필요하다. Exa Lite의 품질이 Auto 대비 실제 작업에서 얼마나 떨어지는지 구체 수치 미공개다.

왜 중요한지

AI 코딩 에이전트의 웹 그라운딩 비용을 직접 낮추는 업데이트다. Dynamic Highlights GA(토큰 95%↓)와 $4/1,000요청 Lite 티어는 에이전트 서비스 운영비를 바로 줄이는 레버다. 사내 AX 에이전트나 검색 기반 RAG를 돌리는 팀은 즉시 도입 검토할 만하다.

특히 코딩 문서·레포 검색(WebCode 75.5%) 강화는 개발자용 에이전트 워크플로우에 직결된다. 검색 품질이 곧 에이전트 답변의 그라운딩 품질이 되는 구조에서, 가격과 토큰 효율이 동시에 개선된 이번 업데이트는 그라운딩 스택 재점검의 계기가 된다.
