크래프톤, 자체 개발 30B급 LLM '라온-1 미니' 프리뷰 공개 — MoE+선형 어텐션, Apache 2.0으로 HF 배포 (10/21)

2026-10-23 · AX 트렌드 · 원문 이슈 #3381

2026년 10월 21일, 크래프톤이 자체 개발한 30B급(300억 개 매개변수) 거대언어모델(LLM) 라온-1 미니(Raon-1 mini)의 프리뷰 버전을 공개했다. 모델 구조 설계부터 초기 학습까지 전 과정을 크래프톤이 독자적으로 수행한 프롬 스크래치(From Scratch) 방식이다. AI 플랫폼 허깅페이스(Hugging Face)에 아파치 2.0 라이선스로 공개됐다. 누구나 무료로 내려받아 연구·상업용 서비스·제품 개발에 쓸 수 있다 (중앙일보, 2026-10-21).

핵심 수치. 전체 매개변수 — 300억(30B). 추론 시 활성화 — 40억(4B)만. 공개일 — 10/21(프리뷰). 라이선스 — Apache 2.0. 지원 언어 — 한국어·영어.

MoE + 선형 어텐션 — 전체 300억 중 추론엔 4B만

  • 전문가 혼합(MoE) 구조를 적용해 전체 300억 개 매개변수 가운데 추론 과정에서 40억 개(4B)만 활성화한다. 추론 비용이 4B급 모델 수준이라 단일 GPU 서버에서도 vLLM 등으로 돌리기 현실적인 규모다 (디지털데일리).
  • 크래프톤이 자체 개발한 선형 어텐션(Linear Attention) 기술을 결합해 연산 부담을 줄이고 응답 속도·추론 비용을 개선했다.
  • 크래프톤은 비용 효율성을 LLM 경쟁력의 핵심으로 설정하고, 단순 벤치마크 점수보다 실사용 활용성을 기준으로 모델을 개발했다는 입장이다 (중앙일보).

사이즈 감이 오면 바로 실험할 수 있는 규모다. vLLM으로 띄우는 건 이렇게 단순하다:

from vllm import LLM

# Raon-1 mini (MoE 30B/4B-active) — HF에서 Apache 2.0으로 배포
llm = LLM(model="krafton-ai/Raon-1-mini-preview")
out = llm.generate(["한국어 지시를 따르는 에이전트 백엔드로 쓰기 좋은 이유를 설명해줘."])
print(out[0].outputs[0].text)

한국어 대화·에이전트 특화 — 개발자가 주목할 지점

  • 개발 역량을 자연스러운 한국어 대화·지시 이행 능력·에이전트 수행 역량·빠른 응답 속도에 집중했다 (서울경제).
  • 한국어 기반 AI 에이전트·AX 서비스의 백엔드 모델로 바로 실험해 볼 수 있는 오픈 모델이 하나 더 생긴 셈이다. 카카오 Kanana 계열 등 한국 기업의 오픈소스 LLM 공개가 이어지는 흐름 속에서 선택지가 늘어나고 있다.
  • 이번 공개는 크래프톤이 올해 4월 출범한 AI 모델 브랜드 라온(Raon)의 기술 확장이기도 하다. 라온 브랜드로는 이미 음성 언어 모델·실시간 음성 대화 모델·음성 합성 모델·비전 인코더 등 4종을 오픈소스로 선보였다 (인더스트리뉴스).
AX TF 관점. 한국어 지시 이행이 강점인 Apache 2.0 MoE 모델이 나온 건, 에이전트 백엔드 후보군의 실전 비교가 더 쉬워졌다는 뜻이다. 추론 시 4B 활성화라 비용이 낮으니 실험 서버에 올리고 한국어 지시 이행·툴콜 정확도를 직접 재보는 게 합리적이다.

아직 안 밝혀진 것 — 벤치마크 점수·비교 대상 미공개

⚠️ 미확인: "해외 동급 대비 우수·일부 지표 국내 대형 모델 근접"은 크래프톤 자체 평가다. 구체적인 벤치마크 점수·측정 조건·비교 대상 모델명은 이번 발표에서 공개하지 않았다 (경향게임스·이데일리). 실제 성능 검증은 정식 버전 출시 시 공개 예정인 테크니컬 리포트를 기다려야 한다. 보도에는 허깅페이스 공개가 명시됐지만 구체적인 모델 페이지 주소는 기사에 없어 실제 다운로드 경로도 미확인이다.

배경 — 크래프톤 AI 조직의 연구 역량

크래프톤 AI 연구 조직은 NeurIPS, ICML, ICLR 등 주요 국제 AI 학회에 지금까지 논문 54편을 발표했으며, 올해 NeurIPS 2026에서는 메인 트랙 논문 9편이 채택됐다 (중앙일보). 크래프톤은 프리뷰의 성능을 개선해 정식 버전을 출시할 계획이다. 정식 출시 시점에는 학습 과정과 최종 성능 평가 결과를 담은 기술 보고서(테크니컬 리포트)를 공개할 예정이다 (디지털데일리).
