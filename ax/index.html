AI/AX 트렌드를 개발자 관점에서 정리한 글 모음.

#3277 OpenAI의 'GPT-6 family로 소프트웨어 유지보수' — 죽은 코드·기능 스위치·CI 최적화 실전 프롬프트 OpenAI Core Experimentation 팀이 GPT-6 패밀리(Codex + GPT-6 Astra, GPT-6.1 Sol)로 자사 코드베이스 유지보수를 돌린 실전 기록. 1,400건 이상의 정리 PR 병합, 죽은 코드 제거·오래된 기능 스위치 추적·CI 비용 절감에 실제로 쓰인 프롬프트의 구조를 개발자 관점에서 정리한다.
#3273 tester-army 'e2e': 에이전틱 E2E 프레임워크에 검증·마이그레이션 스킬 2종 추가 tester-army의 오픈소스 E2E 프레임워크 e2e에 두 개의 실전 스킬이 붙었다. /create-verification-skill은 코딩 에이전트에게 자기 작업물을 스스로 검증하는 증거 루프를 장착하고, /migrate-to-e2e는 기존 Playwright·Cypress 스위트를 한 조각씩 옮기는 '둘 다 green' 경로를 제공한다.
#3270 mobile-jev: Jev 판단 모델이 구동하는 실기기 Android 에이전트 droidrun의 mobile-jev는 TypeSafe Jev 판단 모델과 Mobilerun 클라우드 디바이스 API를 결합한 Android 에이전트다. Uber 데모 21초/9액션, ADB 없이 실기기를 조작하고, 완료는 모델의 DONE 응답이 아닌 화면 검증으로 증명한다.
#3269 jevtest: Jev 판단 모델이 구동하는 평문 모바일 E2E 테스트 Just-Betr의 jevtest는 TypeSafe Jev(System One) 판단 모델로 움직이는 Android/iOS 평문 E2E 테스트 프레임워크다. YAML 한 장으로 테스트를 쓰고, 모든 판단은 lockfile에 기록되어 --lock frozen이면 네트워크도 API 키도 없이 정확히 리플레이된다.
#3194 billion-context: 코딩 에이전트 컨텍스트를 5배 아껴 쓰는 압축 프록시 에이전트와 모델 API 사이에 끼는 컨텍스트 압축 프록시 billion-context. 모델이 직접 압축 타이밍을 정하는 구조, 4개의 컨텍스트 관리 도구, 그리고 주장 뒤의 미확인 수치를 개발자 관점에서 정리한다.
