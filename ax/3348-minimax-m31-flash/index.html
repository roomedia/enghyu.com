MiniMax, 'M3.1 Flash' 공식 출시 — 익명 모델 'Space Bunny'의 정체 공개, DeepSWE 73.7%·가격 $0.15/$0.60

2026-10-22 · AX 트렌드 · 원문 이슈 #3348

2026년 10월 19일, MiniMax가 공식 블로그를 통해 'M3.1 Flash'를 공식 출시했다. 핵심은 발표 자체보다 정체 공개다. 익명으로 200조(200 trillion) 토큰 이상을 처리하며 개발자 커뮤니티에서 정체가 화제였던 'Space Bunny'가 M3.1 Flash의 초기 버전이었다는 사실을 회사가 공식 확인했다.

핵심 수치 세 가지. 첫째, DeepSWE v1.1 73.7% — 복잡한 소프트웨어 개발 태스크 벤치마크. 둘째, 에이전트 태스크 전체 사용 비용이 전작 대비 70% 감소, 온라인 추론 속도는 거의 3배. 셋째, 정액제 가격은 입력 $0.15 / 출력 $0.60 (100만 토큰당, 캐시 입력은 $0.015).

'Space Bunny'의 정체

흐름을 정리하면 이렇다. 9월 27일, M3.1-Flash-Preview가 MiniMax Code에 조용히 탑재됐다(#2957). 같은 시기 OpenRouter에 'stealth/space-bunny-alpha'라는 익명 모델이 무료로 등장해 200조 토큰 넘게 처리되며 정체가 화제가 됐다. 커뮤니티는 토크나이저 지문 분석으로 MiniMax 계열임을 추정했지만(The Neuron·CellCog 보도), 회사는 침묵을 지켰다.

그리고 10월 17일, 경쟁작 DeepSeek V4.1-Flash-1017이 공개됐다(#3327). 이틀 뒤 MiniMax가 정식 발표·벤치마크·가격을 한 번에 공개하며 응수한 셈이다. 경량 에이전트 모델 3파전(DeepSeek V4.1 Flash · GLM 5.3 Flash · MiniMax M3.1 Flash)이 본격화되는 모양새다.

가격과 속도

가격은 정액제다. 입력 $0.15 / 출력 $0.60 / 캐시 입력 $0.015 (100만 토큰당). 속도도 명시했다. 온라인 추론 속도는 거의 3배, 출력 속도 200+ TPS · 중앙값 170+ TPS. 에이전트 태스크 전체 사용 비용이 전작 대비 70% 감소했다고 주장한다.

사용 경로는 이미 열려 있다. MiniMax API · M Plan · MiniMax Code에서 즉시 이용 가능하다. 모델 가중치는 "will be released later"(구체 일정 미공개)이고, 더 큰 'Pro' 모델도 추후 출시 예정이다.

⚠️ 미확인: 모든 벤치마크 수치는 MiniMax 자체 발표 수치로 제3자 독립 검증은 아직 없다. 모델 가중치 공개의 구체 일정은 미공개다. Space Bunny가 익명 운영 중 처리한 200조 토큰의 성격(어떤 워크로드·품질이었는지)도 공개되지 않았다. $0.15/$0.60 가격의 지속 가능성·레이트 리밋 같은 한계 조건도 미공개다.

왜 중요한지

에이전틱 코딩용 경량 모델 티어에서 DeepSWE 73.7%급 성능을 Claude Sonnet 5($2/$10) 대비 1/20 수준 비용으로 쓸 수 있다는 점은, 에이전트 기반 개발 워크플로우의 러닝코스트 구조를 바꿀 수 있다. AX TF 입장에서는 모델 라우팅·폴백 체인 설계 시 저비용 고속 티어의 실전 옵션이 하나 더 늘어난 셈이며, Android 개발 워크플로우에 코딩 에이전트를 붙이는 비용 허들도 낮아진다.
